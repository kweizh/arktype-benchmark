## Key Design Decisions

1. **Pattern over format**: `@ark/json-schema@0.0.4`'s string parser only handles `minLength`, `maxLength`, `pattern` — not `format`. The email and UUID patterns from ArkType's source are used directly.

2. **Inlined recursive schema**: `@ark/json-schema@0.0.4` lacks `$ref`/`$defs` support, so the Comment type is inlined to a finite depth (5 levels), covering all test fixtures.

3. **`.allows()` for validation**: Avoids cross-module `instanceof` failures between the top-level `arktype@2.2.0` and the version bundled inside `@ark/json-schema@0.0.4`.
