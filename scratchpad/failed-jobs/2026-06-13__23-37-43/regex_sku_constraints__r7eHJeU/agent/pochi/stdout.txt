The SKU Catalog Validator is implemented at `/home/user/myproject` with two files:

### `src/validator.ts`
- Defines `skuType` using `type("string").narrow(...)` — the regex `^[A-Z]{2}-\d{4}-[a-z]{3}$` is enforced via a narrow predicate on the individual string type (no manual `.test()` post-filtering outside the schema).
- Defines `CatalogSchema` as an object with:
  - `vendorId`: `"string.uuid"` — ArkType's built-in UUID keyword
  - `skus`: the SKU type array constrained with `.atLeastLength(1).atMostLength(200)`
- Chains a second `.narrow()` on the whole catalog object for uniqueness — the predicate calls `ctx.reject({ path: ["skus"], ... })` when a duplicate is detected, producing a structured `ArkError` whose path includes `skus`.

### `cli.ts`
- Reads stdin to end, parses JSON (reporting `INVALID:` on parse failure), runs `validateCatalog()`, then prints either:
  - `VALID\n<json>\n` on success
  - `INVALID: <error summary>\n` on failure
- Always exits with code 0.
