**Implementation:**
```typescript
import { type } from "arktype";

export const PasswordSchema = type("string >= 8").configure({
  actual: () => "<redacted>",
});
```

**How it works:**
- `type("string >= 8")` creates an ArkType schema requiring a string with minimum length of 8 characters (equivalent to `minLength(8)`)
- `.configure({ actual: () => "<redacted>" })` overrides the `actual` error message writer — instead of embedding the real password value (e.g., `"short"`) in the error message, it always returns the literal string `<redacted>`
