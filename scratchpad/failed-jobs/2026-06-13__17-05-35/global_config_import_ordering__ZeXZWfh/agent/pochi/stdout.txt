**Why this happens:** ArkType's `configure()` mutates a shared global registry (`$ark.config`). The `type()` function reads the resolved config at import time when building schema nodes. If `type()` is imported before `configure()` is called, the schema is built with default config values and the subsequent `configure()` call has no retroactive effect on already-created schemas.
