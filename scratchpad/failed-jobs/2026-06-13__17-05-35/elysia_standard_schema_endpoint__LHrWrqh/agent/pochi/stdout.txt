## Created File

**`/home/user/myproject/src/server.ts`** — The server implementation:

```ts
import { Elysia } from "elysia";
import { type } from "arktype";

const userSchema = type({
  username: "string.alphanumeric >= 3 <= 20",
  email: "string.email",
  age: "number.integer >= 18",
});

const app = new Elysia()
  .post("/user", ({ body }) => {
    return { username: body.username };
  }, {
    body: userSchema,
  })
  .listen(3000);
```

## How it works

- **ArkType `type({...})`** creates a schema instance that implements the **Standard Schema V1** interface (`~standard` property with `validate` method). This is passed directly to Elysia's `body:` option (NOT wrapped in `t.Object`).
- **Elysia** detects the `~standard` property and uses `schema["~standard"].validate(value)` for validation. If validation fails (issues returned), Elysia responds with HTTP 422.
- **ArkType ignores undeclared keys by default**, so extra fields in the JSON body are silently accepted.
