The schema uses the required tuple expression syntax `["string.numeric.parse", "|>", "number % 2"]` to pipe a numeric string parse morph into a modulo divisor constraint, ensuring only even integers pass validation.

**validate.ts:**
```typescript
import { type } from "arktype";

const schema = type({
  score: ["string.numeric.parse", "|>", "number % 2"],
});

const input = JSON.parse(process.argv[2]);
const result = schema(input);

if (result instanceof type.errors) {
  console.log(`INVALID: ${result.summary}`);
  process.exit(1);
} else {
  console.log(`OK: ${JSON.stringify(result)}`);
  process.exit(0);
}
```
