```ts
import { defineConfig } from "vite";
import arkenv from "@arkenv/vite-plugin";

export default defineConfig({
  plugins: [
    arkenv({
      VITE_API_URL: "string.url",
      VITE_FEATURE_FLAG: "boolean",
    }),
  ],
});
```

**How it works:**
- `"string.url"` uses arkenv's built-in URL keyword, which rejects anything that isn't a well-formed URL string.
- `"boolean"` uses arktype's boolean type; arkenv's coercion (enabled by default) automatically converts string values like `"true"` / `"false"` from the environment to proper booleans before validation.
- The plugin runs its `config` hook at the very start of `vite build`, so the process aborts with a non-zero exit code and a clear `ArkEnvError` message before any bundling occurs.
