### How it works

```
string  ──narrow──►  string matching ISO_8601_WITH_TZ  ──pipe──►  new Date(s)
```

Three ArkType steps are chained on a single `Type`:

| Step | ArkType API | Purpose |
|---|---|---|
| `type("string")` | primitive keyword | Rejects anything that isn't a string |
| `.narrow(s, ctx => …)` | narrowing predicate | Runs the strict regex; calls `ctx.reject(…)` (returning the error object to signal failure) when the string has no timezone |
| `.pipe(s => new Date(s))` | morph | Converts the validated string to a `Date` |

### The timezone-mandatory regex

```
/^\d{4}-(0[1-9]|1[0-2])-([12]\d|0[1-9]|3[01])
 T([01]\d|2[0-3]):[0-5]\d
 (:[0-5]\d(\.\d+)?)?
 (Z|[+-]([01]\d|2[0-3]):[0-5]\d)$/i
```

The final group `(Z|[+-]([01]\d|2[0-3]):[0-5]\d)` is **required** (not `?`), so strings without a trailing `Z` or `±HH:MM` are rejected at the `narrow` step before the `pipe` ever runs.
