## Schema design

```ts
const Username = type(/^[a-zA-Z][a-zA-Z0-9]{2,18}$/);
```

A single ArkType expression — passing a `RegExp` literal directly to `type()` produces a `string`-constrained type that validates against the pattern with no manual `.test()` calls anywhere in the code. The regex encodes all four rules at once:

| Part | Rule |
|---|---|
| `^[a-zA-Z]` | Must start with a letter |
| `[a-zA-Z0-9]{2,18}` | 2–18 more alphanumeric characters |
| `$` | No trailing non-alphanumeric chars |
| Total length | 3–19 characters |
