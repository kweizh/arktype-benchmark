The calculator engine is implemented with two TypeScript files under `/home/user/myproject`:

### `operations.ts`
Defines five binary operations (`add`, `subtract`, `multiply`, `divide`, `modulo`) each wrapped with `arktype`'s `type.fn`:
- All accept `number` args and return `number`
- **`divide`**: uses `"number < 0 | number > 0"` to reject divisor `0`
- **`modulo`**: uses `"number % 1 & (number < 0 | number > 0)"` to reject non-integer divisors and `0`

### `cli.ts`
- Reads a single JSON line from stdin with shape `{"op": "...", "a": number, "b": number}`
- Uses `fn("'add'|'subtract'|'multiply'|'divide'|'modulo'", "number", "number", ":", "number")` to validate the dispatcher boundary
- Single `try/catch` around the dispatch call catches `TraversalError` and prints `ERR <message>`
- On success prints `OK <result>`
- Always exits with code `0`
